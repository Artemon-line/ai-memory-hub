    Importer Compatibility Matrix

    Generated for ai-memory-hub 1.0.0 on 2026-10-26.

    Every source client has exactly one required pin. Exact release pins are used only when fixture evidence identifies that release; otherwise the pin names the bounded format, rolling-service endpoint, repository contract, or user-authored contract. A pin is not a promise that unknown future client releases are compatible.

    Detailed evidence

    claude-code-session-jsonl

    • Client pins: Claude Code - observed-jsonl (Format version)
    • Artifact or command: Copy a closed top-level session JSONL file.
    • Default local location: $CLAUDE_CONFIG_DIR/projects//*.jsonl (defaults to ~/.claude)
    • Contract status: Observed internal format
    • Supported envelope: Observed session-scoped JSONL user and assistant message envelopes.
    • Fixture evidence: tests/fixtures/importers/claude_code_session_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_claude_code_session_fixture_keeps_visible_text_and_safe_provenance
    • Known omissions: Subagents, system prompts, thinking, tools, usage, compaction, and snapshots.
    • Unknown-format fallback: Export a readable transcript and use manual.

    codex-rollout-jsonl

    • Client pins: Codex CLI and app - 0.152.0 (Exact client release)
    • Artifact or command: Copy a closed persisted rollout JSONL file.
    • Default local location: $CODEX_HOME/sessions/YYYY/MM/DD/ (defaults to ~/.codex/sessions)
    • Contract status: Observed internal format
    • Supported envelope: Observed session_meta plus canonical user/assistant response_item messages.
    • Fixture evidence: tests/fixtures/importers/codex_rollout_anonymized.jsonl, tests/fixtures/importers/codex_rollout_rich_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_codex_rollout_jsonl_fixture_maps_only_canonical_messages_and_provenance, tests/unit/test_importers.py::test_codex_rollout_rich_fixture_keeps_visible_messages_only
    • Known omissions: Reasoning, instructions, tools, approvals, usage, startup context, and result-only streams.
    • Unknown-format fallback: Create a speaker-labelled transcript and use manual.

    copilot-activity-csv

    • Client pins: Microsoft Copilot - activity-history-csv (Rolling service contract)
    • Artifact or command: Export all activity history from the Microsoft privacy dashboard.
    • Default local location: Browser download directory; no stable local application path.
    • Contract status: Documented user-facing export
    • Supported envelope: CSV with exact Conversation, Time, Author, and Message columns.
    • Fixture evidence: tests/fixtures/importers/copilot_activity_anonymized.csv
    • Focused tests: tests/unit/test_importers.py::test_copilot_activity_csv_fixture_is_grouped_and_chronological
    • Known omissions: Non-conversation activity and account-specific alternate export shapes.
    • Unknown-format fallback: Convert reviewed content to a speaker-labelled transcript and use manual.

    copilot-cli-events-jsonl

    • Client pins: GitHub Copilot CLI - 1.0.88 (Exact client release)
    • Artifact or command: Copy an inactive session's events.jsonl.
    • Default local location: $COPILOT_HOME/session-state//events.jsonl (defaults to ~/.copilot)
    • Contract status: Observed internal format
    • Supported envelope: Observed start/resume metadata and top-level message envelopes; legacy 1.0.54 is tested.
    • Fixture evidence: tests/fixtures/importers/copilot_cli_events_v1_anonymized.jsonl, tests/fixtures/importers/copilot_cli_events_resumed_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_copilot_cli_v1_fixture_maps_text_and_safe_provenance, tests/unit/test_importers.py::test_copilot_cli_resumed_fixture_accepts_legacy_message_envelopes
    • Known omissions: System/synthetic prompts, reasoning, subagents, tools, permissions, and telemetry.
    • Unknown-format fallback: Use /share file <PATH> and import the Markdown with manual.

    deepseek-harness-session-jsonl

    • Client pins: DeepSeek Harness - session-format-0..4 (Format version)
    • Artifact or command: Download a session log, safely extract it, and select the root session JSONL.
    • Default local location: Extracted session.jsonl or session.vN.jsonl; no stable local path.
    • Contract status: Documented user-facing export
    • Supported envelope: Canonical Harness session formats 0 through 4.
    • Fixture evidence: tests/fixtures/importers/deepseek_harness_session_v0_descendant_anonymized.jsonl, tests/fixtures/importers/deepseek_harness_session_v4_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_deepseek_harness_v4_fixture_maps_text_and_safe_provenance, tests/unit/test_importers.py::test_deepseek_harness_v0_descendant_accepts_compact_messages
    • Known omissions: ZIPs, attachments, internal context, reasoning, tools, usage, and merged descendants.
    • Unknown-format fallback: Export visible content as a speaker-labelled transcript and use manual.

    deepseek-share-json

    • Client pins: DeepSeek web - share-content-api-v0 (Rolling service contract)
    • Artifact or command: Save one conversation's share-content response as JSON.
    • Default local location: Browser download or saved API response; no stable local path.
    • Contract status: Observed internal format
    • Supported envelope: Successful share response with messages under data.biz_data.
    • Fixture evidence: tests/fixtures/importers/deepseek_share_anonymized.json
    • Focused tests: tests/unit/test_importers.py::test_deepseek_share_json_fixture_flattens_conversational_fragments
    • Known omissions: Account history, search snippets, and unrelated browser-extension JSON.
    • Unknown-format fallback: Copy reviewed visible text into a speaker-labelled file and use manual.

    droid-exec-json

    • Client pins: Factory Droid - capture-v1 (Repository-owned contract)
    • Artifact or command: Record droid exec in the versioned ai-memory-hub capture envelope.
    • Default local location: Recorder-selected path; Droid has no portable history export.
    • Contract status: ai-memory-hub-defined capture
    • Supported envelope: Capture version 1 with one-shot and stream-jsonrpc kinds.
    • Fixture evidence: tests/fixtures/importers/droid_exec_one_shot_anonymized.json, tests/fixtures/importers/droid_exec_stream_anonymized.json
    • Focused tests: tests/unit/test_importers.py::test_droid_exec_one_shot_fixture_maps_prompt_result_and_provenance, tests/unit/test_importers.py::test_droid_exec_stream_fixture_coalesces_only_completed_visible_turns
    • Known omissions: Raw result JSON, TUI history, share links, telemetry, and incomplete turns.
    • Unknown-format fallback: Capture prompt and response in a speaker-labelled file and use manual.

    gemini-cli-session-json

    • Client pins: Gemini CLI - session-object+shared-history (Format version)
    • Artifact or command: Run /chat share <FILE> or legacy /export-session <FILE>.
    • Default local location: User-selected export path; do not use autosaved internal JSONL.
    • Contract status: Documented user-facing export
    • Supported envelope: Session-object and shared-history JSON export envelopes.
    • Fixture evidence: tests/fixtures/importers/gemini_cli_export_session_anonymized.json, tests/fixtures/importers/gemini_cli_shared_history_anonymized.json
    • Focused tests: tests/unit/test_importers.py::test_gemini_cli_export_session_fixture_keeps_visible_text_and_provenance, tests/unit/test_importers.py::test_gemini_cli_shared_history_fixture_excludes_injected_context_and_tools
    • Known omissions: Autosaved JSONL, injected context, thoughts, tools, token counts, and diagnostics.
    • Unknown-format fallback: Export or copy a readable transcript and use manual.

    hermes-session-jsonl

    • Client pins: Hermes Agent - sessions-export-jsonl (Format version)
    • Artifact or command: Run hermes sessions export <FILE> [--redact].
    • Default local location: User-selected path; live state defaults to ~/.hermes/state.db.
    • Contract status: Documented user-facing export
    • Supported envelope: One complete Hermes session object per JSONL line.
    • Fixture evidence: tests/fixtures/importers/hermes_sessions_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_hermes_fixture_maps_live_text_and_safe_provenance, tests/unit/test_importers.py::test_hermes_multi_session_fixture_preserves_boundaries
    • Known omissions: Live databases, Markdown, rewound rows, synthetic context, tools, and identifiers.
    • Unknown-format fallback: Use a reviewed Hermes Markdown export with manual.

    manual

    • Client pins: Manual transcript - speaker-labelled-text (User-authored input)
    • Artifact or command: Create UTF-8 text with supported speaker labels.
    • Default local location: User-selected text file or standard input.
    • Contract status: User-authored transcript
    • Supported envelope: Speaker-labelled text with non-empty user and assistant messages.
    • Fixture evidence: tests/fixtures/importers/manual_transcript_synthetic.txt
    • Focused tests: tests/unit/test_importers.py::test_manual_transcript_fixture_returns_unified_payload
    • Known omissions: Structured provenance, branches, tools, attachments, and ambiguous text.
    • Unknown-format fallback: Correct the speaker labels or write a source-specific importer.

    opencode-session-json

    • Client pins: OpenCode - session-export-json (Format version)
    • Artifact or command: Run opencode session export <ID> --sanitize (legacy: opencode export <ID>).
    • Default local location: Standard output or user-selected file; do not copy internal storage.
    • Contract status: Documented user-facing export
    • Supported envelope: OpenCode session export JSON with info and ordered messages.
    • Fixture evidence: tests/fixtures/importers/opencode_session_anonymized.json
    • Focused tests: tests/unit/test_importers.py::test_opencode_session_json_fixture_maps_text_and_provenance
    • Known omissions: Internal storage, reasoning, tool-only turns, and synthetic/ignored text.
    • Unknown-format fallback: Export Markdown or copy visible text and use manual.

    pi-session-jsonl

    • Client pins: Pi - pi-session-v3 (Format version), Oh My Pi - oh-my-pi-session-v3 (Format version), OpenClaw - openclaw-legacy-session-v3 (Format version)
    • Artifact or command: Copy a closed version 3 JSONL tree or coordinated OpenClaw archive.
    • Default local location: $PI_CODING_AGENT_DIR/sessions; OpenClaw archive location varies.
    • Contract status: Observed internal format
    • Supported envelope: Version 3 Pi-family trees, Oh My Pi headers, and legacy OpenClaw variants.
    • Fixture evidence: tests/fixtures/importers/pi_session_anonymized.jsonl, tests/fixtures/importers/oh_my_pi_session_anonymized.jsonl, tests/fixtures/importers/openclaw_session_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_pi_session_fixture_reconstructs_only_the_active_branch, tests/unit/test_importers.py::test_pi_session_detects_variants_and_omits_private_records
    • Known omissions: HTML, abandoned branches, live OpenClaw SQLite, thinking, tools, and usage.
    • Unknown-format fallback: Export visible content as a speaker-labelled transcript and use manual.

    qwen-code-session-export

    • Client pins: Qwen Code - json+jsonl-export (Format version)
    • Artifact or command: Run /export json or /export jsonl.
    • Default local location: $QWEN_HOME/projects//chats; export path varies.
    • Contract status: Documented user-facing export
    • Supported envelope: Self-contained JSON, metadata-first JSONL, or bounded message-only JSONL.
    • Fixture evidence: tests/fixtures/importers/qwen_code_session_anonymized.json, tests/fixtures/importers/qwen_code_session_anonymized.jsonl
    • Focused tests: tests/unit/test_importers.py::test_qwen_code_json_fixture_maps_text_and_safe_provenance, tests/unit/test_importers.py::test_qwen_code_jsonl_fixture_maps_canonical_export
    • Known omissions: Session listings, presentation exports, system records, tools, usage, and file lists.
    • Unknown-format fallback: Use a reviewed Markdown export with manual.
