# Historical Improvement Plans

The files under `docs/improvements/` preserve design decisions, compatibility
notes, and validation history from completed and partially completed programs.
They are not the active backlog, and unchecked boxes may be stale.

Use [Project status](project_status.md) for the reconciled done, partial, and
not-started classification. Use [Documentation and planning](plans.md) for the
GitHub issue-backed planning policy.

Notable completed records include retrieval precision, context building,
conversation grouping, MCP response formatting, edge-case coverage, handoff
memory, graph quality gates, and beta governance. Remaining outcomes are being
consolidated into reviewed GitHub epics instead of additional Markdown plans.
