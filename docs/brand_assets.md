# Brand Assets

ai-memory-hub uses a small vector-first rose and voice inspired memory hub mark.
The mark is designed to remain readable as a favicon while still working as a
docs logo, Connect UI mark, demo watermark, and future plugin/icon asset.

## Files

Use the SVG files as the source assets:

- `docs/assets/brand/ai-memory-hub-mark.svg`
- `docs/assets/brand/ai-memory-hub-wordmark.svg`

Favicon and app-icon exports are also checked in:

- `docs/assets/brand/favicon.svg`
- `docs/assets/brand/favicon.ico`
- `docs/assets/brand/favicon-16x16.png`
- `docs/assets/brand/favicon-32x32.png`
- `docs/assets/brand/favicon-48x48.png`
- `docs/assets/brand/apple-touch-icon.png`
- `docs/assets/brand/icon-192.png`
- `docs/assets/brand/icon-512.png`

The Connect UI has matching packaged copies under `memory/ui/connect/static`
because those assets are served by the application, not the documentation site.

## Usage

- Use the mark for favicons, small social/profile icons, app tiles, and video
  watermarks. The rose points and quiet voice shape should stay visible.
- Use the wordmark for README images, slide titles, and demo intros where there
  is enough horizontal space.
- Keep the mark on a quiet background with enough contrast. Do not render it
  over screenshots or terminal output unless it sits in a solid corner badge.
